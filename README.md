## features
- add products with unique product code checks
- display full catalog in tabular format
- search product by code
- update price for an existing product
- delete product by code
- filter low stock products (quantity < 10) into a separate list
- filter products by price range (rs. 500 to rs. 1000)

## usage
run the script using python 3:

```bash
python3 inventory.py
```
